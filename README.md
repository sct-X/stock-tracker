# The Snack Tab

A small Home Screen app for an office drinks fridge: tap a drink to record a sale, keep tabs for people who pay later or pay ahead, and track the kitty (with cash-outs).

- No server, no account, no tracking. This site only serves the app's code.
- All data stays on the phone, encrypted (AES-GCM, key derived with PBKDF2 from mobile number + passcode).
- Works offline once installed.

Install on iPhone: open the site in Safari → Share → **Add to Home Screen**.
